它能做什么

从一次提问到工单闭环，全部链路可观测。

01

多轮对话 · 云端持久化

会话列表支持新建与切换，消息逐条写入云数据库，刷新页面不丢失，右侧实时展示处理链路。

02

FAQ 知识库检索

对问题、关键词、分类做加权打分；高置信度命中时直接返回标准答案，避免大模型编造政策。

03

意图识别 + RAG 生成

退款 / 查询订单 / 技术支持 / 通用四类，大模型 JSON 分类；未命中时注入 Top 3 FAQ 流式生成回复。

04

自动转人工

用户主动要求、模型判定无法答复、或满意度 ≤ 2 星时自动创建工单并更新会话状态。

05

满意度评价

1–5 星加文字评价写入云端，后台实时汇总平均分与分布。

06

管理后台

5 个 KPI、满意度 / 意图 / 近 7 日趋势图、工单状态管理、对话记录全文展开与时间筛选。

一条消息的处理链路

每一步都会实时显示在对话页右侧的「本轮分析」面板中。

1 · 输入与落库写入 messages 表，拉取最近 10 条历史作为上下文
2 · 意图分类大模型输出 JSON，失败则降级为本地关键词分类
3 · 知识库检索加权打分，命中高分段直接返回标准答案
4 · 大模型回复未命中时注入 Top 3 FAQ，流式生成并逐字上屏
5 · 兜底与评价无法解决自动建工单；会话结束收集满意度
